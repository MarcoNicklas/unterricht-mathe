1 · Parabel-Grundlagen

Der Graph einer quadratischen Funktion heißt Parabel.

Merke – zwei Formen

Allgemeine Form

y = ax² + bx + c

Scheitelform

y = a · (x − xS)² + yS

Scheitelpunkt S(xS | yS) direkt ablesbar.
Achtung: Bei (x + 2)² ist xS = −2!

Der Öffnungsfaktor a

  • a > 0: nach oben geöffnet, a < 0: nach unten geöffnet
  • |a| > 1: gestreckt (schmaler), |a| < 1: gestaucht (breiter)
  • Ablesen: Vom Scheitel 1 nach rechts → die Höhenänderung ist a
  • c ist der Schnittpunkt mit der y-Achse: (0 | c)

Ausprobieren – verändere a und den Scheitel:

Umrechnen zwischen den Formen

Scheitelform → allgemeine Form
Binomische Formel anwenden, ausmultiplizieren, zusammenfassen.

y = 4 · (x + 1)² − 2
y = 4 · (x² + 2x + 1) − 21. binomische Formel
y = 4x² + 8x + 4 − 2ausmultiplizieren
y = 4x² + 8x + 2zusammenfassen

Allgemeine Form → Scheitelpunkt
xS mit der Formel berechnen, dann yS durch Einsetzen.

y = 2x² − 6x + 4
xS = −b2a = 64 = 1,5
yS = 2 · 1,5² − 6 · 1,5 + 4 = −0,5
S(1,5 | −0,5) → y = 2 · (x − 1,5)² − 0,5

Alternativ: quadratische Ergänzung.

2 · Quadratische Gleichungen lösen

Brauchst du für Nullstellen, Schnittpunkte und fast jede Prüfungsaufgabe.

Merke – Lösungsformel („Mitternachtsformel“)

Gleichung zuerst auf die Form 0 = ax² + bx + c bringen.

x1/2 = −b ± √D2a   mit   D = b² − 4ac

Diskriminante D entscheidet über die Anzahl der Lösungen:

  • D > 0 → zwei Lösungen
  • D = 0 → eine Lösung
  • D < 0 → keine Lösung

Beispiel: 0 = 4x² + 10x + 4

a = 4,   b = 10,   c = 4Koeffizienten ablesen
D = 10² − 4 · 4 · 4 = 100 − 64 = 36 > 0→ zwei Lösungen
x1/2 = −10 ± √362 · 4 = −10 ± 68
x₁ = −0,5  und  x₂ = −2

Nullstellen einer Parabel sind die Schnittpunkte mit der x-Achse. Dort gilt y = 0 → Gleichung 0 = ax² + bx + c mit der Lösungsformel lösen. Ergebnis als Punkte angeben: N₁(x₁ | 0), N₂(x₂ | 0).

Übungen

Gib D und die Lösungen ein. Gibt es weniger als zwei Lösungen, lass die übrigen Felder leer.

3 · Funktionsgleichung aufstellen

In der Abschlussprüfung muss fast immer eine Funktionsgleichung aus gegebenen Punkten ermittelt werden.

Rezept
  1. Allgemeine Form aufschreiben: y = ax² + bx + c
  2. Was ist schon bekannt? Der Öffnungsfaktor a? Der y-Achsenabschnitt c (Punkt mit x = 0)?
  3. Die übrigen Punkte einsetzen → pro Punkt eine Gleichung, vereinfachen.
  4. 2 Gleichungen mit 2 Unbekannten lösen: Gleichsetzungs- oder Einsetzungsverfahren.
  5. Fehlende Variable berechnen, Funktionsgleichung angeben, Probe machen.

Die Parabel verläuft durch A(2 | 1) und B(−8 | 6) und hat den Öffnungsfaktor a = −0,25.

y = −0,25x² + bx + ca in die allgemeine Form einsetzen
A einsetzen: 1 = −0,25 · 2² + b · 2 + c → 1 = −1 + 2b + c → c = −2b + 2nach c auflösen: | + 1 | − 2b
B einsetzen: 6 = −0,25 · (−8)² + b · (−8) + c → 6 = −16 − 8b + c → c = 8b + 22nach c auflösen: | + 16 | + 8b
Gleichsetzen: −2b + 2 = 8b + 22 → −10b = 20 → b = −2c fällt weg, nur noch b bleibt übrig
b einsetzen: c = −2 · (−2) + 2 = 6
y = −0,25x² − 2x + 6Probe mit B: −0,25 · 64 + 16 + 6 = 6 ✓

Die Parabel verläuft durch P(−1 | 10), Q(0 | 5,5) und R(3 | −2).

Q liegt auf der y-Achse → c = 5,5 → y = ax² + bx + 5,5
P einsetzen: 10 = a · (−1)² + b · (−1) + 5,5 → 4,5 = a − b → a = b + 4,5
R einsetzen: −2 = a · 3² + b · 3 + 5,5 → −7,5 = 9a + 3b| − 5,5
a = b + 4,5 einsetzen: −7,5 = 9(b + 4,5) + 3b → −7,5 = 12b + 40,5 → 12b = −48 → b = −4Einsetzungsverfahren

Die Parabel hat den Scheitel S(2 | −1) und verläuft durch P(4 | 7).

Scheitelform nutzen: y = a · (x − 2)² − 1
P einsetzen: 7 = a · (4 − 2)² − 1 → 8 = 4a → a = 2

Allgemeine Form: y = 2(x² − 4x + 4) − 1 = 2x² − 8x + 7

Die Gerade verläuft durch A(−1 | 5) und B(3 | −3). Ansatz: y = mx + t

m = y₂ − y₁x₂ − x₁ = −3 − 53 − (−1) = −84 = −2
A einsetzen: 5 = −2 · (−1) + t → 5 = 2 + t → t = 3

4 · Lagebeziehung von Gerade und Parabel

Wie viele gemeinsame Punkte haben eine Gerade und eine Parabel?

1. Fall: Sekante

Gerade und Parabel schneiden sich.
Zwei gemeinsame Punkte · D > 0

2. Fall: Tangente

Gerade und Parabel berühren sich.
Ein gemeinsamer Punkt · D = 0

3. Fall: Passante

Gerade und Parabel schneiden sich nicht.
Kein gemeinsamer Punkt · D < 0

Vorgehen (rechnerische Lösung)
  1. Gleichsetzen: yG = yP (Klammern auflösen, binomische Formel!)
  2. Alles auf eine Seite bringen: 0 = ax² + bx + c
  3. Diskriminante D = b² − 4ac berechnen → Anzahl der gemeinsamen Punkte
  4. x-Werte mit der Lösungsformel berechnen
  5. x-Werte in die Geradengleichung einsetzen (einfacher!) → y-Werte → Punkte angeben

Durchgerechnete Beispiele

yG = −2x − 2   und   yP = 4 · (x + 1)² − 2

−2x − 2 = 4 · (x + 1)² − 2gleichsetzen
−2x − 2 = 4 · (x² + 2x + 1) − 2 = 4x² + 8x + 2binomische Formel, ausmultiplizieren
0 = 4x² + 10x + 4| + 2x + 2
D = 10² − 4 · 4 · 4 = 36 > 0 → zwei Schnittpunkte (Sekante)
x1/2 = −10 ± 68 → x₁ = −0,5   x₂ = −2
y₁ = −2 · (−0,5) − 2 = −1   y₂ = −2 · (−2) − 2 = 2 → S₁(−0,5 | −1),  S₂(−2 | 2)

yG = x − 0,5   und   yP = −0,5 · (x − 2)² + 1

x − 0,5 = −0,5 · (x² − 4x + 4) + 1 = −0,5x² + 2x − 1
0 = −0,5x² + x − 0,5| − x + 0,5
D = 1² − 4 · (−0,5) · (−0,5) = 1 − 1 = 0 → ein Berührpunkt (Tangente)
x = −1 ± 02 · (−0,5) = 1   →   y = 1 − 0,5 = 0,5 → B(1 | 0,5)

yG = −0,2x − 1   und   yP = 2 · (x − 1,5)² − 0,5

−0,2x − 1 = 2 · (x² − 3x + 2,25) − 0,5 = 2x² − 6x + 4
0 = 2x² − 5,8x + 5| + 0,2x + 1
D = 5,8² − 4 · 2 · 5 = 33,64 − 40 = −6,36 < 0 → kein gemeinsamer Punkt (Passante)

Ausprobieren

Gerade y = mx + t
