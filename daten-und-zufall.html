Ergebnisraum, Ergebnismenge, Ereignisraum – was ist was?
  • Ergebnisraum (Lehrplan) = Ergebnismenge (Zusammenfassung): die Menge Ω aller Ergebnisse.

Welcher Wahrscheinlichkeitsbegriff passt?

Kein einzelnes Ergebnis, sondern ein Wunsch, zu dem mehrere Ergebnisse passen. Wähle ein Ereignis oder tippe selbst Würfelseiten an.

Ω = {1; 2; 3; 4; 5; 6}
0 %
0 % unmöglich50 %100 % sicher

Ein Ereignis E fasst alle Ergebnisse zusammen, die einen Wunsch erfüllen – es ist eine Teilmenge von Ω.

Laplace-FormelP(E) = |E||Ω| = Anzahl passende ErgebnisseAnzahl aller Ergebnisse
P(E₂) = 46 = 66,6 % ≈ 66,67 %
ArtBeispielP
unmöglichE₁: „eine 8“
E₁ = { } = ∅ (leere Menge)		0 %
möglichE₂: „größer als 2“
E₂ = {3; 4; 5; 6}		zwischen 0 und 100 %
sicherE₃: „zwischen 0 und 7“
E₃ = Ω		100 %

Das Gegenereignis E̅ („E quer“, Komplementärereignis) enthält alle übrigen Ergebnisse aus Ω – den „Rest“.

E₂ = {3; 4; 5; 6} → E̅₂ = {1; 2}
E̅₂: „Ich werfe eine Zahl kleiner als 3.“
P(E̅₂) = 26 ≈ 33,33 %

Es giltE ∪ E̅ = Ω – zusammen alle Ergebnisse
E ∩ E̅ = ∅ – kein gemeinsames Ergebnis
P(E) + P(E̅) = 1 = 100 % → P(E̅) = 1 − P(E)

In der Zusammenfassung steht „E ∩ E̅ = Ω“ – richtig ist E ∪ E̅ = Ω.

Typischer FehlerGegenereignis von „größer als 2“ ist nicht „kleiner als 2“ – die 2 fehlt! Gegenereignis von „höchstens 4“ ist „mindestens 5“, von „mindestens einmal“ ist es „keinmal“.

Eingaben: Bruch 3/8 · Dezimalzahl 0,375 · Prozent 37,5 % · Menge {1; 2; 3}. Prozentwerte auf zwei Nachkommastellen runden.

Merkzettel

Relative Häufigkeit · Winkelmaß

h = H : n · Winkel = h · 360°

Kennzahlen

x̄ = Summe : n · xmod = häufigster Wert · xmed = Mitte der Rangliste (n ungerade: (n+1)/2-ter Wert; n gerade: Mittel aus n/2-tem und (n/2+1)-tem Wert) · R = Max − Min

Laplace-Formel

P(E) = |E||Ω| – nur wenn alle Ergebnisse gleich wahrscheinlich sind

Gegenereignis

P(E̅) = 1 − P(E) · E ∪ E̅ = Ω · E ∩ E̅ = ∅

Zählprinzip

Anzahl der Pfade = Produkt der Möglichkeiten je Stufe (z. B. 2 · 2 · 2 = 8)

Pfadregeln

1. Pfadregel: entlang eines Pfades multiplizieren (Ergebnis) · 2. Pfadregel: Pfadwahrscheinlichkeiten addieren (Ereignis)

Ohne Zurücklegen

Nenner wird bei jedem Zug um 1 kleiner, Zähler der gezogenen Farbe ebenso.
